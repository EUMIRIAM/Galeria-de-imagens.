# Galeria de Imagens

**Tecnologias utilizadas:** HTML, CSS e JavaScript.

## Sobre o projeto

A aplicação funciona da seguinte forma: o usuário clica na imagem desejada para visualizá-la em destaque, exibindo somente a imagem selecionada.

Também é possível fechar a imagem ampliada clicando no botão "X" ou fora da imagem.
